# Marketplace

A responsive marketplace storefront prototype built with HTML, CSS, and vanilla JavaScript.

## Pages

- `index.html` — marketplace homepage
- `produk.html` — product listing
- `detail.html` — product detail
- `keranjang.html` — shopping cart
- `checkout.html` — checkout form
- `konfirmasi.html` — order confirmation

## Run locally

Open `index.html` in your browser, or use the VS Code Live Server extension for local development.
